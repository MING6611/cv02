# 贾明洁个人网页简历｜参考版

## 怎么打开
直接双击 `index.html`，浏览器即可打开。

## 项目结构
- `index.html`：网页内容和结构
- `style.css`：视觉样式、布局、手机端适配
- `script.js`：简单的移动端菜单交互
- `images/`：以后放个人照片、作品图

## 注意
本参考版主要根据上传 PDF 的第 5 页信息制作。原 PDF 共 5 页，存在不同版本的工作经历、教育信息等内容，因此这里没有混用不同版本。
